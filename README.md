# 🏆 عرش التخطيط — لعبة كويز تفاعلية

لعبة كويز ملكية الطابع لمراجعة درس **التخطيط** من مقرر مبادئ إدارة الأعمال.
مبنية بـ **Next.js 16 + TypeScript + Tailwind CSS 4**، بواجهة عربية كاملة (RTL) وتصميم ليلي فخم (كحلي داكن + ذهبي).

## ✨ المحتوى والمزايا

- **٤٠ سؤالًا** من الدرس نفسه: المفهوم، الخصائص، الفوائد، الأنواع، العناصر، شروط الأهداف والسياسات، الخطوات، خصائص التخطيط الفعال، المعوقات — مع توضيح بعد كل إجابة.
- **٣ أنماط لعب:**
  - 🌙 رحلة الملكة — ١٥ سؤالًا، ٣ قلوب، مؤقت لكل سؤال
  - ⚡ سباق الزمن — ٩٠ ثانية لأسئلة متتالية، كل إجابة صحيحة تضيف وقتًا
  - 👑 التحدّي الملكي — ١٢ سؤالًا، خطأ واحد يطيح بك، مع سلّم نقاط يتضاعف
- **مساعدات ذهبية:** حذف إجابتين (٥٠:٥٠)، وقت إضافي، تخطّي السؤال
- سلاسل إجابات صحيحة 🔥، مؤثرات صوتية، قصاصات ورق احتفالية، ورُتب ختامية
- **لوحة أبطال مشتركة** لكل نمط (أعلى ١٠ نتائج)
- شاشة مراجعة الأخطاء بعد كل جولة
- متوافقة تمامًا مع الجوال

## 🚀 النشر على Vercel (خطوات مبسطة)

> اللعبة جاهزة للنشر. قاعدة البيانات تدعم أي PostgreSQL سحابي مجاني (Neon / Vercel Postgres / Supabase) — والجدول ينشئ نفسه تلقائيًا أول مرة، بدون أي أوامر ترحيل.

1. ارفع هذا المستودع إلى GitHub.
2. افتح [vercel.com](https://vercel.com) وسجّل الدخول بـ **Continue with GitHub**.
3. **Add New… → Project** واستورد المستودع — سيتعرف على Next.js تلقائيًا.
4. أنشئ قاعدة بيانات مجانية (إحدى طريقتين):
   - **الأسرع:** من داخل مشروع Vercel → تبويب **Storage** → أنشئ قاعدة **Neon Postgres** → اربطها بالمشروع (سيضيف متغير `DATABASE_URL` تلقائيًا).
   - **أو يدويًا:** أنشئ حسابًا في [neon.tech](https://neon.tech) → انسخ **Connection String** → في Vercel: Settings → Environment Variables → أضف `DATABASE_URL` بقيمة الرابط.
5. اضغط **Deploy** — وخلال دقيقة ستحصل على رابط مثل: `https://اسم-مشروعك.vercel.app`

## 🛠️ التشغيل محليًا (للمطورين)

```bash
npm install
npx prisma generate        # يهيئ عميل قاعدة SQLite المحلية
npm run dev                # افتح http://localhost:3000
```

متغير البيئة المطلوب محليًا (ملف `.env`):

```
DATABASE_URL="file:./db/custom.db"
```

عند نشرها على Vercel لا تستخدم SQLite — استخدم رابط PostgreSQL كما في خطوات النشر أعلاه.

## 📁 البنية

```
src/
  app/                  الصفحات والمسارات (Next.js App Router)
    api/scores/         واجهة لوحة الأبطال (GET / POST)
  components/game/      شاشات اللعبة: الرئيسية، اللعب، النتائج، المراجعة، لوحة الأبطال
  lib/
    questions.ts        بنك الأسئلة الأربعين
    game-data.ts        إعدادات الأنماط والرتب
    scores-store.ts     طبقة التخزين (SQLite محليًا / PostgreSQL سحابيًا)
    sound.ts            المؤثرات الصوتية (Web Audio)
    confetti.ts         محرك القصاصات الاحتفالية
prisma/schema.prisma    مخطط قاعدة البيانات المحلية
public/fonts/           خطوط Amiri و Tajawal
```
